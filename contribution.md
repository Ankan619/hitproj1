Contributing Guidelines

This repository is used for practice and learning basic file and command-line operations.

Purpose:
The files a.txt, b.txt, and c.txt are part of the assignment and are intended to
practice file handling commands.

Guidelines:

1. Do not delete existing files (a.txt, b.txt, c.txt).
   These files must remain in the repository for evaluation purposes.

2. Copying files:
   - When practicing copy operations, create a new file instead of overwriting existing ones.
   - Example: copy a.txt to a new file name.

3. Moving files:
   - Move files only into clearly named folders if required.
   - Avoid moving original assignment files out of the root directory.

4. Renaming files:
   - Use meaningful names when renaming files.
   - Do not rename original files unless the assignment explicitly asks for it.

5. Avoid common mistakes:
   - Do not use destructive commands without understanding them.
   - Double-check commands before pressing Enter.
   - Avoid overwriting files unintentionally.

6. Commits:
   - Each change should be committed separately with a clear commit message.
   - Example: "Practice file rename operation" or "Add guidelines for file handling".

Following these rules helps maintain clarity and prevents accidental data loss.
