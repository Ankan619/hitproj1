# HitPractice

HitPractice is a practice repository used to demonstrate basic open-source
contribution workflows along with simple programming examples.

This repository includes a **Java Swing GUI mini project** added as an
enhancement to help beginners understand graphical user interface development
using Java.

---

## Java GUI Mini Project

## project Name
**Student Grade Calculator (GUI)**

## scription
A simple Java Swing–based desktop application that allows users to enter marks
for three subjects and calculate the total marks and final grade.

This example is designed for beginners to understand:
- Java Swing components
- Event handling
- Basic conditional logic
- GUI-based application execution

---

## Features
- Input marks for three subjects
- Calculate total marks
- Display grade (A / B / C / Fail)
- Error handling for invalid inputs
- Simple and clean GUI layout
